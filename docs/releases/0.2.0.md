# AlphaWinnow 0.2.0

Local-first expression research with caller-measured search. No account,
network service, market dataset, or AlphaGen installation is required.

## Highlights

- Embed a bounded `MeasuredSearchSession`: ask for formulas, evaluate them in
  your own system, and tell the session their finite outcomes. Checkpoints bind
  the configuration and catalog; evaluator identity is supplied by the caller.
- Choose explicit exploration, mutation, and parent-retention policies.
  Latest-batch score and uniform policies support controlled retention studies;
  neither implies better financial performance.
- Guide structural search with immutable feedback or archive-seeded parents;
  inspect operator weighting and evidence provenance in the manifest.
- Evaluate the expanded embedded catalog using the optional causal numeric
  backend. Unsupported generation-enabled custom operators fail closed.

The complete `measured_search` example runs with `--no-default-features` and a
synthetic negative-node-count objective. The separate `measured_search_stdio`
example supports local evaluator integration via JSONL.

## Migration from 0.1.x

This is a pre-1.0 breaking release. Change library dependencies to `0.2` only
after publication, or use a local path dependency to test the prepared tree.

1. Update explicit `SearchRunOptions` literals; use
   `..SearchRunOptions::default()` for options you do not override. Downstream
   construction of public manifest/checkpoint structs also needs the new fields.
2. Structural-search manifests now write schema 8, and structural checkpoints
   use schema 2. Old schema-1 structural checkpoints cannot resume with this
   release. Keep the 0.1.x binary for existing runs; do not edit schema numbers
   to bypass validation. Candidate JSONL remains schema 4 (readers accept 1–4).
3. The new measured-search checkpoint schema 1 is a distinct format, not an
   upgrade path for CLI structural checkpoints. Restore with matching config
   and catalog, and the same caller-defined evaluator semantics.
4. Rebuild semantic indexes from original expressions: `rank(rank(x))` now
   collapses to the `rank(x)` family. Binary root-product normalization also
   covers custom binary multiplication ASTs. Negative root direction and
   scaling inside nonlinear operators remain distinct.
5. The embedded catalog expanded. Preserve original catalogs, executable
   versions, and inputs when reproducing historical work; the same seed does
   not guarantee the same expressions across releases.
6. Numeric evaluator construction rejects any enabled generation operator
   without a backend, even if the expression being evaluated does not use it.
   Supply a supported catalog rather than assuming parse support means numeric
   support. Existing and newly added rolling operators have operator-specific
   variance/window semantics documented and tested in `numeric.rs`.

## Scope of evidence

This release adds research tools, not a validated trading strategy. Structural
scores and synthetic examples are not IC, Sharpe, PnL, or profitability claims.
No claim of superiority over AlphaGen, benchmark leadership, or independent
market generalization is made. The published crate excludes the local
`alphagen-rs/` and `benchmarks/` research directories and private run artifacts.

## Before publishing

Run the repository's format, strict Clippy, all-feature and library-only tests,
MSRV check, rustdoc, synthetic examples, and package verification. Review the
crate file list and commit contents. Local verification does not replace the
Linux/macOS/Windows CI matrix, CodeQL, or final signed-off release run.
Homebrew/Scoop stay on the previous published version until the workflow has
real new archive checksums; never invent or reuse old checksums for 0.2.0.
